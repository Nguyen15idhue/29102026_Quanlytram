# Dữ liệu bản đồ

## vietnam-provinces.geojson

- Nội dung: `FeatureCollection` ranh giới 34 tỉnh/thành, geometry `MultiPolygon`,
  property `name`.
- Nguồn: do người dùng dự án cung cấp (chưa xác định giấy phép gốc).
- Trước khi phát hành ra ngoài, cần bổ sung nguồn/giấy phép chính xác vào mục này.
- Đây là bản sao ổn định; không đặt file trong `frontend/public/guide/` vì thư mục
  đó bị `scripts/build-guide.mjs` xoá và tạo lại.
